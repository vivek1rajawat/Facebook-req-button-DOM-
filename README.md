# Tum Meri Wajah Ho - Personal Love Website 💕

A beautiful, emotional personal website expressing deep love and affection. This project transforms a simple interface into an immersive romantic experience with multiple interactive sections.

## 🌟 Features

### 🏠 Welcome Section - "Tum Meri Wajah Ho..."
- Animated star background with twinkling effects
- Elegant typography using Google Fonts (Playfair Display, Dancing Script)
- Soft gradient background with center glow box
- Parallax scrolling effects

### 🧡 Importance Section - "Tere Hone Se..."
- Four emotional messages with minimalist icons (🌼💬❤️💫)
- Smooth scroll-triggered animations
- Pastel gradient background
- Responsive card layout

### 🧠 Thought Section - "Agar tu na hoti toh..."
- Blurred cloud background effect  
- Large, readable typography with proper spacing
- Full-width emotional paragraph design

### 🔐 Lock Box Section - "Ek Paigam Dil Se"
- **Password-protected secret message** 
- **Password: `tumnaam`**
- Beautiful celebration effect with floating hearts
- Romantic letter revealed after correct password
- Error handling with shake animation for wrong passwords

### 🌌 Ending Section - "Mera Dil Tumse Judaa Nahi"
- Fading moon/sunset background
- Large quote typography
- Final emotional message

## 🎨 Design Features

- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Google Fonts**: Playfair Display (headings) and Dancing Script (cursive text)
- **Animations**: AOS (Animate On Scroll) library for smooth transitions
- **Background Effects**: Animated gradients, floating particles, star twinkling
- **Interactive Elements**: Music toggle, password unlock, hover effects
- **Typography**: Carefully crafted text hierarchy for emotional impact

## 🛠️ Technical Implementation

- **HTML5**: Semantic structure with proper accessibility
- **CSS3**: Advanced animations, gradients, and responsive design
- **JavaScript**: Interactive password functionality, AOS animations, particle effects
- **External Libraries**: AOS animation library for scroll effects

## 🚀 How to Use

1. Open `index.html` in any modern web browser
2. Scroll through the beautiful sections
3. When you reach the Lock Box section, enter the password: **`tumnaam`**
4. Enjoy the celebration effect and read the secret romantic message
5. Toggle the music button (🎵) in the top-right corner
